Privacy Policy for Overton Browser Shield

Last updated: October 3, 2026

1. Overview

Overton Browser Shield is a browser extension that provides proxy controls inside Google Chrome. The extension works only inside the browser and is not a system-wide VPN for the entire device.

2. Data We Process

The extension may process the following data:

  • Anonymous install ID: a random extension installation identifier created locally in the browser. It is used to provide a trial period without Telegram authorization.
  • Subscription token: a token used to verify active access and retrieve the list of proxy servers.
  • Extension settings: theme, auto-connect, kill switch, WebRTC setting, split tunneling mode, excluded/included domains, and (if added) a custom proxy together with its routing.
  • Technical connection data: selected proxy server, connection status, and session start time.
  • Custom proxy (experimental): the address and the list of user-added proxies (including login/password if entered) are stored locally in chrome.storage.local, used only to configure Chrome proxy settings and to test connectivity, and are never sent to Overton servers. During a connectivity test the extension temporarily routes a request to www.cloudflare.com/cdn-cgi/trace through the tested proxy to determine the exit IP, then immediately restores the previous proxy settings.
  • Telegram profile data, if the user signs in through the Telegram bot: name, username, and subscription status.
  • Public IP address and country code: shown in the popup so the user can verify the connection. They are requested from www.cloudflare.com/cdn-cgi/trace (fallback: api.ipify.org), displayed locally, and are not stored or linked to the account.
  • Connectivity check: the extension periodically requests https://www.gstatic.com/generate_204 to verify that the proxy connection works. No personal data is sent with this request.

The extension does not collect page contents, passwords, messages, banking data, or user files, and it does not store, analyze, or sell your browsing history. Destination domains are processed only in memory while routing traffic and answering proxy authentication requests, and this information is not retained as history.

3. How We Use Data

Data is used only to operate the service:

  • provide a 2-day trial period;
  • verify active subscription status;
  • connect the browser to Overton proxy/VPN servers;
  • automatically provide proxy authentication credentials;
  • save extension settings;
  • notify about subscription expiration;
  • support WebRTC calls when this option is enabled.

4. Traffic Routing

When VPN is enabled, browser network traffic may pass through Overton proxy/VPN servers. While traffic is routed, the extension and the selected server necessarily process the destination domains and IP addresses of requests in order to deliver them; this information is used only for routing and is not stored as browsing history. If the user has added a custom proxy (experimental), traffic may pass through that user-provided proxy. The extension works only inside Chrome and does not route traffic from other applications on the device.

If WebRTC is enabled, WebRTC/UDP connections, including Discord and other calling services, may work directly and may reveal the real IP address. This setting is provided for call compatibility.

5. Data Storage

Some data is stored locally in the browser using chrome.storage.local. Overton servers store data required for subscriptions, trial access, access verification, and technical operation of the service.

6. Third Parties

We do not sell users' personal data. Data may be processed by third-party services only when necessary to operate the service, such as Telegram for bot authorization and support, payment providers for subscription payments, and infrastructure providers for server hosting.

7. Data Deletion

Users can delete local extension data by removing the extension from the browser. To request deletion of server-side data, contact Overton support.

8. Security

We take reasonable technical measures to protect data and access to proxy/VPN servers. However, no method of transmission or storage can be guaranteed to be completely secure.

9. Limited Use Disclosure

Overton Browser Shield complies with the Chrome Web Store Limited Use requirements:

  • User data is used only to provide or improve this extension's single purpose: configuring and maintaining the browser's proxy connection.
  • User data is not sold, and is not transferred to third parties except where necessary to provide the service, to comply with applicable laws, for security purposes, or as part of a merger, acquisition, or sale of assets.
  • User data is never used to serve personalized, retargeted, or interest-based advertising.
  • User data is not read by humans, except with the user's consent (for example, support requests), where necessary for security purposes, to comply with applicable laws, or when aggregated and anonymized for internal operations.
